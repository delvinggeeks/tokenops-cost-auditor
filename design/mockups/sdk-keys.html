What this is
Ingest keys for sending usage from your own code — the SDK, a script, or CI — straight into your audits.
What a key can do
Write usage counts to your account. Nothing else — it can read nothing, so a leaked key cannot see a single number of yours.
What we accept
Token counts, timestamps, model names. Requests carrying prompt or completion text are rejected at the door — we refuse the data we promise never to hold.

One environment variable in your stack; your usage shows up here. Counts only — the endpoint refuses text.
