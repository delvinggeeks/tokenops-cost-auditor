Design decisions & why this is the moat

Deterministic, not a model. Every figure is Σ cost_usd / token-count arithmetic on the machine-verified rate card — no LLM, no trained model, no estimate. Same logs → byte-identical breakdown, every run. That reproducibility + FR-22 privacy (we never read prompt text, only counts) is exactly what a customer's finance team can trust and a GPT-wrapper competitor cannot match.
  • Many granular findings, not categories (founder ask). One audit → a breakdown across 4 dimensions × N slices, and every inefficient slice becomes its own precise dollar line. The dimensions multiply the finding surface without any estimation.
  • Savings stay 100% precise + disjoint. Insight dollars reuse the SAME detector math (D1/D2/… sliced by dimension), so a slice's $ never double-counts a detector finding — it's the same money, attributed to where it lives. Informational slices (concentration, peak-hour) carry $0 and say so.
  • Reachability (R-VERTICAL). A "Breakdown" destination in the app (Monitor group), plus a breakdown section in the report — reachable, not a dead widget.
  • Honest coverage. Per-request dimensions (route / hour / prompt-size) need per-request logs; a connected aggregate source labels them "requires per-request logs" (same law as D4–D9), reinforcing why upload/SDK is the deep path.
  • Reconciles to the invoice + data-quality report. % priced / % attributed / untagged / unpriced are shown, so an enterprise trusts the numbers are COMPLETE, not cherry-picked — the audit-grade property LLM tools can't offer.
  • X-02 respected. The budget figure is a DISPLAY REFERENCE for variance only — informational, never an enforcement gate on the customer's traffic (same posture as the existing forecast overspend alert). No proxy, no policy enforcement, ever.
  • Plain-English + technical. Each insight leads with the human sentence; the exact token/rate arithmetic is the technical detail (the finding grammar we just shipped).
  • One designed delight. The vitals strip: five exact numbers that let a founder feel their whole tokenomics in one glance, with the two unhealthy ones in the waste colour.
